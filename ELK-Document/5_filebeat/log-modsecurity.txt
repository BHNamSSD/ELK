⚙️ 1. Filebeat config (QUAN TRỌNG NHẤT)
Bạn phải bật JSON parsing ngay từ Filebeat để không bị lỗi string.
📌 filebeat.yml
filebeat.inputs:
  - type: log
    paths:
      - /var/log/nginx/modsec_audit.log   # sửa đúng path của bạn

    json.keys_under_root: true
    json.add_error_key: true
    json.expand_keys: true

    # mỗi dòng là 1 JSON object
    json.overwrite_keys: true

output.logstash:
  hosts: ["192.168.22.10:5044"]   # IP Logstash
 
note:
| Config            | Tác dụng               |
| ----------------- | ---------------------- |
| `keys_under_root` | Đưa JSON lên root      |
| `add_error_key`   | Báo lỗi nếu parse fail |
| `expand_keys`     | Tách key dạng `a.b`    |
| `overwrite_keys`  | Cho JSON ghi đè field  |

📌 filter (parse + flatten + SOC ready)
Log của bạn bị nested sâu (transaction → request → messages)
→ cần flatten để dùng Kibana dễ.
filter {

  # rename cho dễ dùng
  mutate {
    rename => { "[transaction][client_ip]" => "client_ip" }
    rename => { "[transaction][time_stamp]" => "timestamp" }
    rename => { "[transaction][host_ip]" => "server_ip" }
    rename => { "[transaction][request][method]" => "http_method" }
    rename => { "[transaction][request][uri]" => "url" }
    rename => { "[transaction][response][http_code]" => "status_code" }
  }

  # lấy message đầu tiên
  mutate {
    add_field => {
      "attack_type" => "%{[transaction][messages][0][message]}"
      "rule_id" => "%{[transaction][messages][0][details][ruleId]}"
    }
  }

  # parse timestamp
  date {
    match => ["timestamp", "EEE MMM dd HH:mm:ss yyyy"]
    target => "@timestamp"
  }

  # thêm field SOC useful
  mutate {
    add_field => {
      "event_type" => "waf"
      "log_source" => "modsecurity"
    }
  }
}
